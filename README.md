# BIT2118 Scientific Computing

Python examples for scientific-computing tasks 2–20.

## Setup

```bash
pip install -r requirements.txt
```

## Run examples

Scripts are stored in [code/](/workspaces/BIT2118-Scientific-Computing/code). Run an example from the repository root, for example:

```bash
python code/task16_numerical_integration.py
```

Tasks 8, 10, 13, 14, 15, 17, 18, and 20 open plots. Set `MPLBACKEND=Agg` when running in a non-GUI environment.
